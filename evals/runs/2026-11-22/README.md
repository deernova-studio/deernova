## 规则检查（scripts/lint-ui.mjs）

| --- | --- | --- |
| 智能体配置 | 69 / 130 | 0 / 5 |
| 看板 | 81 / 81 | 0 / 0 |

baseline 的错误主要是写死的颜色、字号、圆角和间距，三页都用了渐变，看板用了 700 字重、彩虹色标签和蓝紫渐变按钮。deernova 剩下的提醒都是 `gap: 6px` 这类没有对应设计变量的间距，其中 6px 来自 style 自己的分组列表。

## 看得出来的差别

- **深色模式**：三个 baseline 都没有深色模式；deernova 三页都直接跟着 tokens.css 变。
- **统一**：deernova 三页的顶栏、侧栏、列表行、按钮、开关一模一样；baseline 三页各是一种风格（暖灰、蓝色强调、蓝紫渐变）。
- **AI 味**：baseline 的看板是典型的生成感：彩色标签、渐变按钮、倾斜的拖动卡片、每张卡片一排小图标。deernova 的看板只有过期和阻塞有颜色。
- **但 deernova 偏空、偏小**：设置页在 1280 宽的窗口里只占中间一小块，行高 32、输入框 28、标题 18，看起来比 baseline 小一号、空一半。baseline 的设置页反而更饱满：头像、每行一句说明、同步状态。这一点是 deernova 当前最明显的弱项。
- **成本**：deernova 的三次构建读了 15–25 份文档，用了 2–3.5 倍的时间和 token（baseline 6.4 万–8.5 万 token、1.5–4 分钟；deernova 15 万–26 万 token、4–9.5 分钟）。

## 文档自相矛盾的地方（构建时被 agent 发现）

1. 看板页给卡片加了阴影，style 说卡片没有阴影。
2. 看板页的列名加粗，style 说分组标题用常规字重。
3. style 说状态标签带一个小圆点，看板页的示例没有。
4. 设置页要求每组一个短标题，它自己的示例却没有。
5. 智能体配置等页面每节标题下有一句说明（`dn-builder-lede`），style 说区块标题不带副标题。
6. 弹窗文档说危险确认的焦点放在「取消」，没有覆盖「先输入账户名再确认」这种情况。
7. style 的分组列表用了 `gap: 6px`，设计变量里没有 6px。

## 下一步

- 修掉上面 7 处矛盾。
- 重新看桌面密度：Web 应用里的行高、输入框高度和标题字号是否该大一档，以及设置页这类窄内容在宽屏里怎么不显得空。
- 把 lint 接进 `npm test`，并补上看不出来但能从源码查的规则（单选组散铺、开关用彩色、选中用彩色）。
